# 导出、导入与分享

导出日记用于分享，或创建备份以迁移到另一台设备。

## 导出

在日记详情页可以选择导出格式：

| 格式 | 用途 |
| --- | --- |
| **Markdown** | 纯文本通用格式，方便迁移到其它笔记软件 |
| **Word (.docx)** | 交给需要交稿的场景 |
| **PDF** | 打印、存档 |
| **长图** | 分享到社交平台 |

多媒体内容会一并处理，长图导出会保留排版样式。

## 备份

在 **我的 → 导入与导出** 中导出备份，内容包括日记、分类、地点与引用的媒体。备份包可以：

- 保存在本机或任意网盘；
- 在另一台设备上通过同一页面恢复。

备份不包含应用设置、自定义字体、AI 对话或服务凭据，换机后需要重新配置。ZIP 文件**未加密**，请妥善保存。

::: tip 建议的节奏
换机前、大版本更新前，各做一次完整备份。
:::

## 导入

支持两种来源：

- **Markdown 压缩包**：把其它应用的 Markdown 导出打包成 zip 后导入；
- **本地备份**：恢复由 Moodiary 生成的备份包。

## 分享

分享单篇日记等同于把它导出为所选格式，然后调用系统分享面板，可以直接发送给朋友或保存到相册（长图）。
