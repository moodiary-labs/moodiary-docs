# 备份与同步

Moodiary 支持 WebDAV、S3、局域网传输与本地备份。云端同步可选端到端加密，局域网传输使用加密压缩包。

进入 **我的 → 同步与备份** 配置同步方式。

## 同步方式对比

| 方式 | 适用场景 | 需要配置 |
| --- | --- | --- |
| **局域网同步** | 同一 Wi-Fi 下的两台设备 | 无需账号 |
| **WebDAV** | 坚果云、Nextcloud 等网盘 | 服务器地址、账号 |
| **S3 / MinIO** | 自建对象存储，容量最灵活 | Endpoint、密钥 |

三种方式均支持**增量传输**，同步日记更新并补齐缺失媒体。

## 端到端加密

开启加密后，你只需设置一个 **同步密码**：

- 应用通过 Argon2id 从密码派生密钥，用于保护随机生成的数据密钥；内容使用 AES-GCM 加密；
- 真正加密数据的密钥不会以明文形式离开设备；
- 服务商保存加密内容和经过加密的数据密钥副本。

::: warning 同步密码无法找回
忘记同步密码将无法解密已锁定的云端数据。你可以重置云端后重新上传本地数据；重置会删除云端副本，保留本地数据。
:::

## 局域网同步

1. 两台设备连接同一 Wi-Fi，并都打开 Moodiary；
2. 在接收端进入 **同步 → 局域网 → 接收**；
3. 在发送端选择 **发送**，选中发现的设备，并输入接收端显示的六位配对码。

局域网传输是单向增量传输，使用条目级 AES-256 加密压缩包，无需账号，见[局域网配置](../services/lan)。

::: tip
如果搜索不到对方设备，检查路由器是否开启了「AP 隔离」（客户端隔离）。
:::

## WebDAV

在 **同步 → WebDAV** 中填写：

| 字段 | 说明 |
| --- | --- |
| 服务器地址 | 例如 `https://dav.jianguoyun.com/dav/` |
| 用户名 | 网盘账号 |
| 密码 | 应用密码（部分服务商需要单独生成的授权码） |

详细说明见 [WebDAV 配置](../services/webdav)。

## S3 / MinIO

在 **同步 → S3** 中填写 Endpoint、Bucket、Region、Access Key 与 Secret Key，并可选择是否使用 HTTPS。适合自建 MinIO 或使用任意兼容 S3 协议的对象存储，见 [S3 / MinIO 配置](../services/s3)。

## 备份

在 **我的 → 导入与导出** 中创建备份，并将副本保存到别处。本地备份是未加密 ZIP，云端同步加密不会保护它，见[备份内容](./export-import#备份)。
