# 编辑日记

Moodiary 的编辑器基于 **TipTap**，在原生 WebView 中运行，兼顾富文本能力与流畅度。

## 输入方式

- **所见即所得**：像在普通文档里一样排版，工具栏可以设置标题、加粗、列表、引用等。
- **Markdown 语法**：习惯 Markdown 的话，直接输入 `# 标题`、`- 列表`、`**加粗**`，编辑器会即时转换。

## 插入多媒体

日记不只有文字。通过编辑器工具栏可以插入：

- **图片**：从相册选取或直接拍摄；
- **音频**与**视频**：适合记录一段声音或一段影像。

媒体文件保存在应用的数据目录中，并在[媒体库](./organize#媒体库)中统一管理。

## 标题、分类与天气

在日记的编辑页可以设置：

- **标题**：列表中的第一眼信息；
- **分类**：同一主题的日记归在一起，见[分类](./organize#分类)；
- **心情**：从「糟糕」到「很棒」选择五级心情，也可以留空，见[心情洞察](./organize#心情洞察)；
- **天气与地点**：可手动选择，或在配置[和风天气](../services/weather)后自动获取。

## 删除与回收站

删除日记后会先进入 **我的 → 回收站**，可以恢复或彻底清除。

::: warning
彻底清除后的日记无法恢复，请谨慎操作。
:::

## 保存与编辑器设置

修改会自动保存，离开日记前请检查保存状态。

在 **设置 → 日记设置** 中可以调整首行缩进，也可以排序或隐藏编辑器工具栏中的工具。
