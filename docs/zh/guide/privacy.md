# 安全与隐私

Moodiary 离线可用，日记保存在本地。使用同步、AI、天气与地图时，相应数据会发送给你选择的服务商。

## 应用锁

在 **设置 → 应用锁** 中可以设置密码锁：

- 密码以 Argon2id 派生后存储，应用本身也无法还原明文；
- 支持使用指纹 / 面容等 **生物识别** 快速解锁；
- 可开启「立即锁定」，切出应用即刻上锁。

也可以在设置中开启后台隐私保护，在应用切换器中隐藏日记内容。

## 数据存储

- 日记与元数据保存在 **SQLite** 中，媒体以独立文件保存在应用私有目录；
- 普通设置使用本地 **MMKV** 存储，敏感凭据使用系统安全存储；
- 只有在使用第三方服务、下载模型等需要联网的功能时才会发起网络请求，详见[隐私政策](../privacy-policy)；
- 没有广告 SDK、没有统计 SDK、没有崩溃上报。

在 **设置 → 存储空间** 中可以查看空间占用，清理缓存、不再使用的模型或媒体。清理前请检查所选项目。

## 同步加密

使用 WebDAV 或 S3 同步时，可以开启[端到端加密](./sync#端到端加密)：

- 同步密码通过 Argon2id 与 AES-GCM 保护数据加密密钥；
- 数据使用 AES-GCM 加密后才会上传；
- 云端保存加密内容和经过加密的数据密钥副本。

局域网传输使用配对码与加密压缩包。[本地备份](./export-import#备份)则是未加密的 ZIP 文件。

## 敏感信息

第三方服务的 API Key（天气、地图、AI）保存在系统安全存储中，请求时会发送给对应服务商用于认证。Moodiary 不会将它们写入[备份](./export-import#备份)或同步数据，换机后需要重新填写。

## 卸载前

卸载应用可能删除本地日记。请先[导出备份](./export-import#备份)，或确认其他位置已有完整副本。
