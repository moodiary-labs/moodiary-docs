# 主题与字体

Moodiary 默认使用一套安静的**黑白灰度**配色，也允许你彻底改掉它。

## 模式

在 **设置 → 显示** 中可以选择：

- **跟随系统**：与系统深浅色模式保持一致；
- **浅色** / **深色**：手动固定。

## 强调色

强调色决定链接、按钮与高亮的颜色，提供三种模式：

| 模式 | 说明 |
| --- | --- |
| **黑白**（默认） | 一套灰度配色，安静克制，与系统提供的壁纸颜色无关 |
| **跟随系统** | 设备支持时，使用系统提供的动态颜色 |
| **自定义** | 从色板中挑选一个喜欢的颜色 |

## 字体

**设置 → 字体样式** 支持导入自定义字体文件：

- 支持常见字体格式，包括 **可变字体**（导入后会显示「可变字体」徽标，并支持调节字重）；
- 导入后的字体保存在应用数据目录中，不包含在备份里，换机后需要重新导入。

## 排版细节

在 **设置 → 日记设置** 中可以调整首行缩进，字号跟随系统设置。

## 心情配色

**设置 → 心情配色** 提供经典、默认、蓝橙与色盲友好配色，用于心情展示。
