# 快速上手

这份指南带你在五分钟内完成第一次记录。

## 1. 创建第一篇日记

打开应用，点击右下角的 **新建** 按钮：

1. 输入标题与正文，正文支持图文混排，也支持 Markdown 语法；
2. 点击工具栏中的图标可以插入图片、音频或视频；
3. 为日记选择一个[分类](./organize#分类)，方便日后查找；
4. 修改会自动保存，离开前请确认保存状态。

日记保存在本地数据库，无需联网。

## 2. 用日历回顾

进入 **我的 → 回顾 → 日历**，按月或年浏览，点击日期即可查看当天日记。

## 3. 找回一篇日记

点击首页顶部的搜索框，输入关键词即可全文检索。忘掉关键词也没关系，可以在[语义搜索](./organize#语义搜索)开启后用一句模糊的描述去找。

## 4. 换个顺手的样式

进入 **设置**，你可以：

- 在 **显示** 中切换浅色 / 深色模式，以及强调色（默认为黑白灰度）；
- 在 **字体样式** 中导入自己喜欢的字体，包括可变字体。

## 5. 接下来做什么

- 想在多台设备间保持一致？阅读[备份与同步](./sync)。
- 想把日记变成 Word、PDF 或长图？阅读[导出、导入与分享](./export-import)。
- 想让天气和地点自动出现在日记里？阅读[天气、地点与足迹](./weather-and-places)，并配置相应的[服务](../services/)。
