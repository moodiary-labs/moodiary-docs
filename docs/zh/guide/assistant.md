# AI 助手

连接你配置的服务商进行对话，并通过工具检索或编辑日记。

## 服务商与端侧模型

### 1. 连接在线服务

支持任意兼容以下协议的服务，包括官方 API 与各类自建网关：

- **OpenAI Chat Completions**
- **OpenAI Responses**
- **Anthropic Messages**

在 **设置 → 智能助手 → 模型供应商** 中新建服务商，填写[基础地址、密钥与模型](../services/ai)。常见服务商可直接选用预设。

### 2. 端侧模型

语义搜索使用本地嵌入模型。在 **设置 → 服务 → 语义检索** 中下载并选择模型后，即可按含义查找日记，见[语义搜索](./organize#语义搜索)。

下载后，向量计算与搜索均可离线运行。自动心情建议已在 2.9.0 移除，写日记时请自行选择心情。

::: tip 对话必须走服务商
对话与日记工具调用由你配置的服务商完成，端侧模型不参与对话。想不依赖第三方云服务，可以自建 Ollama、LM Studio 等本地推理服务，见 [AI 大模型](../services/ai)。
:::

## 它能做什么

助手可以调用一组受控工具来操作你的日记：

- 查询与语义搜索日记；
- 创建、更新、删除日记与分类；
- 记住你告诉它的偏好；
- 在受控沙箱中运行 JavaScript 处理数据。

::: warning 工具权限
默认的 **变更前确认** 模式会确认写入与删除；**自动编辑** 仅确认覆盖正文等破坏性操作；**完全访问** 不再逐项询问。可在 AI 助手设置中选择，也可只对当前对话生效。
:::

## 隐私

- 对话会将消息、附件及工具检索到的日记内容发送给你配置的服务商；
- 语义搜索的向量计算与检索在本地完成；
- 首次使用会展示免责声明，确认后才会启用。
