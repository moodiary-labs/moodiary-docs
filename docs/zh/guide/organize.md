# 分类、检索与日历

通过分类、搜索与日历，回看以前写下的内容。

## 分类

在 **我的 → 分类管理** 中创建和管理分类，写日记时为它选择归属。首页列表可以按分类筛选。

## 全文检索

首页顶部的搜索框使用 **SQLite FTS5** 全文索引：

- 支持中英文与混合输入；
- 结果按相关度排序。

## 语义搜索

不记得准确关键词时，可以通过 **语义搜索** 按含义查找日记：

- 在 **设置 → 服务 → 语义检索** 中下载并选择嵌入模型，下载大小取决于所选模型；
- 之后可以直接用一句自然语言描述去搜索，结果按语义相关度排序。

模型与索引同样保存在本地，不会上传任何内容。

## 日历视图

进入 **我的 → 回顾 → 日历**，可切换月视图与年视图，并按分类筛选。点击日期可查看当天日记，中文日历还会显示农历、节气与节日。

## 心情洞察

写日记时可以选择五级心情，也可以留空。在 **我的 → 心情洞察** 中，按周、月或年查看心情日历、趋势与分布。

升级到 2.9.0 时，旧版心情会转换为相近等级，「学习」「旅行」等场景会转为标签。

## 媒体库

所有插入过日记的图片、音频与视频都会出现在 **媒体库** 中，可以按类型浏览，也可以快速跳转到引用它的日记。

## 回收站

删除的日记先进入 **我的 → 回收站**，可以恢复或彻底清除。回收站也支持按分类筛选。
