# AI 大模型

AI 助手支持接入任意 **OpenAI 兼容** 或 **Anthropic 兼容** 的服务，包括官方 API、各类聚合网关与本地部署的推理服务（如 Ollama、LM Studio）。

## 支持的协议

| 协议 | 适用场景 |
| --- | --- |
| OpenAI Chat Completions | 绝大多数兼容服务 |
| OpenAI Responses | OpenAI 新版接口 |
| Anthropic Messages | Claude 系列及兼容网关 |

## 获取配置信息

- **官方服务**：在 OpenAI / Anthropic 等平台的控制台创建 API Key；
- **聚合网关**：按网关文档获取 Base URL 与 Key；
- **本地服务**：开启 Ollama / LM Studio 的 API 服务。服务运行在电脑上时，手机需填写电脑的局域网地址，例如 `http://192.168.1.10:11434/v1`；`127.0.0.1` 指向手机自身。

## 在 Moodiary 中配置

进入 **设置 → 智能助手 → 模型供应商**，新建服务商：

| 字段 | 说明 |
| --- | --- |
| 名称 | 自定义，用于区分多个服务商 |
| 协议 | 上表中的三种之一 |
| 基础地址 | 预设服务商已锁定，自建服务需手动填写 |
| API Key | 服务商提供的密钥 |
| 默认模型 | 对话使用的模型 |
| 模型列表 | 可手动添加，或从服务商拉取 |

还可以为该服务商开启能力开关：

- **工具调用**（Tool Call）：允许助手检索与操作日记；
- **推理**（Reasoning）：启用所选模型支持的推理选项；
- **附件**（视觉）：允许发送图片。

::: tip 预设
应用内置了常见服务商预设（来自 [models.dev](https://models.dev/) 的公开目录，缓存 24 小时）。选择预设后只需填入 API Key。
:::

## 不想联网？

对话由你配置的服务商处理。也可以自建 Ollama、LM Studio 等推理服务，将内容发送到自己的服务（见上文“本地服务”）。

另有本地嵌入模型负责[语义搜索](../guide/organize#语义搜索)，在 **设置 → 服务 → 语义检索** 中下载并选择后即可离线使用，无需 API Key。

## 模型下载源

在 **设置 → 服务 → Hugging Face 下载源** 中选择官方源，或填写兼容 Hugging Face 的根地址。模型路径由应用自动拼接。此设置只影响模型下载，不会更改对话服务商。

## 隐私

消息、附件及工具检索到的日记内容会发送给你配置的服务商。API Key 保存在系统安全存储中，请求时会发送给该服务商用于认证，不会随[备份](../guide/export-import#备份)迁移。
