# 服务配置总览

写作与浏览可离线使用。天气、地图、AI 与模型下载在 **设置 → 服务** 中配置；同步在 **我的 → 数据同步与备份** 中配置。

| 服务 | 用途 | 是否必需 |
| --- | --- | --- |
| [和风天气](./weather) | 自动记录日记当时的天气 | 可选 |
| [天地图](./map) | 地点管理与足迹地图 | 可选 |
| [WebDAV](./webdav) | 通过网盘同步与备份 | 可选 |
| [S3 / MinIO](./s3) | 通过对象存储同步与备份 | 可选 |
| [局域网同步](./lan) | 同一网络下设备间直连同步 | 无需配置 |
| [AI 大模型](./ai) | AI 助手对话的服务商 | 对话必需；支持 Ollama 等自建服务 |

::: tip 隐私
请求由应用直接发往对应服务商。密钥保存在系统安全存储中，请求时会发送给对应服务用于认证，不会随[备份](../guide/export-import#备份)或同步数据迁移。
:::

## 通用做法

1. 按上方对应指南获取服务地址与凭据；
2. 在相应的服务或同步页面中填写；
3. 回到功能页验证是否生效。

模型下载失败时，可以检查 [Hugging Face 下载源](./ai#模型下载源)。
