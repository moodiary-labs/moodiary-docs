# 隐私政策

**生效日期：2026 年 11 月 2 日**

本政策说明 Moodiary 应用如何处理你的数据。Moodiary 是由 ZhuJHua 与社区贡献者开发的开源日记应用，[源代码](https://github.com/ZhuJHua/moodiary)公开。

## 概览

- **开发者不收集你的数据。** Moodiary 没有账号系统，也没有用于存放你日记的服务器。
- **应用内没有广告、统计或崩溃上报 SDK，** 也不会跟踪你。
- **你的数据默认保存在设备上。** 只有在你使用下文列出的功能时，相关数据才会发送给对应的服务。

## 保存在设备上的数据

以下数据保存在应用的私有存储空间内：

- 日记内容、图片、视频、录音、心情、分类和标签；
- 你添加到日记中的地点和天气；
- AI 助手的会话和记忆；
- 应用设置和错误日志。错误日志只保存在本机，应用不会自动上传。

第三方服务的 API Key 和同步凭据保存在系统的安全存储中。应用锁密码以不可还原的方式（Argon2id）派生后保存。生物识别由系统完成，应用无法获取你的面容或指纹数据。

语义检索和心情建议等端侧能力在本机运行，不会把日记内容发送出去。

## 会离开设备的数据

下表列出 Moodiary 会访问的外部服务。这些服务的请求都会暴露你的 IP 地址等常规网络信息。除 AI 模型目录和模型下载外，都需要你先自行配置或选用。开发者无法访问这些请求中的内容。

| 服务 | 什么时候发送 | 发送什么 |
| --- | --- | --- |
| 你配置的 AI 服务商 | 你向 AI 助手发送消息时 | 你的消息和附件、会话上下文、助手通过工具读取的相关日记内容，以及你的 API Key |
| [models.dev](https://models.dev/) | 查看或选择预设的 AI 服务商和模型时 | 获取模型目录和服务商图标的请求，不包含日记内容 |
| 你配置的 WebDAV 或 S3 服务 | 同步或备份时 | 日记、媒体和设置，以及访问该服务的凭据。开启端到端加密后，服务方只能看到密文 |
| 同一局域网内的其它设备 | 你发起局域网传输并输入配对码时 | 你选择传输的日记数据，传输时经过加密 |
| [和风天气](https://www.qweather.com/)或你填写的 API 地址 | 配置后，为日记获取天气或地点时 | 位置坐标、语言设置和你的 API Key |
| [OpenStreetMap](https://www.openstreetmap.org/) 或[天地图](https://www.tianditu.gov.cn/) | 你选用该地图源并查看地图时 | 地图瓦片请求，会体现你查看的区域。使用天地图时还包括你的 API Key |
| [Hugging Face](https://huggingface.co/) 或你填写的下载源 | 你下载端侧模型时 | 下载模型文件的请求，不包含日记内容 |
| GitHub | 仅 Android 版，你点击“检查更新”时 | 查询最新版本的请求 |

首次使用 AI 助手前，应用会告知你上述数据发送情况，并在你同意后才允许使用。你也可以使用本地部署的模型服务，这样对话不会发送给外部服务商。

这些服务由各自的提供方或你本人运营，并适用其自己的隐私政策。开发者与它们之间没有数据共享安排，请自行判断是否信任所选服务。

你通过系统分享面板分享内容或打开外部链接时，相关内容由你选择的应用或网站处理。

## 系统权限

以下权限只在你使用相应功能时请求，你可以随时在系统设置中关闭：

| 权限 | 用途 |
| --- | --- |
| 相机、麦克风 | 拍摄照片和视频、录制语音，并添加到日记 |
| 照片图库 | 选择要添加到日记的照片和视频，或保存照片和视频 |
| 位置（仅使用期间） | 为日记添加地点和天气。应用不会在后台获取位置 |
| 面容 ID 或指纹 | 开启应用锁后解锁应用 |
| 本地网络 | 与同一 Wi-Fi 下的其它设备互传数据 |

## 数据保留与删除

数据会一直保留在你的设备上，直到你删除。

- **删除日记：** 日记会先移入回收站，从回收站删除后才会彻底清除。
- **删除全部本地数据：** 卸载应用即可。iOS 钥匙串中的凭据可能在卸载后仍然保留；如果开启了系统备份，设备备份中也可能包含应用数据，这部分需要你在系统中管理。
- **删除已同步的数据：** 在你的 WebDAV 或 S3 服务上直接删除。
- **删除发送给 AI 服务商或其它第三方的数据：** 按对应服务的政策办理。
- **撤回同意：** 停止使用相应功能，在应用内移除对应凭据，并在系统设置中关闭相关权限。

开发者不持有你的数据，因此无法替你查询、导出或删除。你可以直接在应用内查看、修改和导出自己的数据。

## 应用商店

你从 App Store 或其它平台下载应用时，平台会按其隐私政策处理相关数据。平台可能向开发者提供汇总的下载和使用统计，以及用户同意共享的崩溃报告，这些信息不含你的日记内容。

## 未成年人

Moodiary 不面向特定年龄段，也不会主动收集任何人的个人信息。未成年人应在监护人指导下使用，尤其是配置和使用第三方服务时。

## 本站与社区

本政策只适用于 Moodiary 应用。本文档站使用了访问统计服务，[官方论坛](https://answer.moodiary.net)由独立的社区系统提供，这些网站会在你访问时处理相应的访问信息。

## 政策变更

政策变更时会更新本页和生效日期。你可以在[文档仓库](https://github.com/ZhuJHua/moodiary-docs)查看历史版本。

## 联系方式

如有疑问，可以通过 [GitHub Issues](https://github.com/ZhuJHua/moodiary/issues) 或[官方论坛](https://answer.moodiary.net)联系我们。公开渠道请勿发布日记内容、API Key 等敏感信息。
