# 隐私政策

**生效日期：2026 年 11 月 2 日**

Moodiary 是 ZhuJHua 与社区贡献者开发的开源日记应用，[源代码](https://github.com/ZhuJHua/moodiary)公开。

## 概览

- **开发者不收集你的数据。** Moodiary 没有账号系统，也没有存放日记的服务器。
- **应用没有广告、统计或崩溃上报 SDK，** 也不会跟踪你。
- **数据默认保存在设备上。** 只有使用下文列出的功能时，才会向相应服务发送数据。

## 保存在设备上的数据

应用的私有存储空间保存：

- 日记内容、图片、视频、录音、心情、分类和标签；
- 日记中的地点和天气；
- AI 助手的会话和记忆；
- 应用设置和错误日志，日志不会自动上传。

API Key 和同步凭据保存在系统的安全存储中。应用锁只保存密码经 Argon2id 派生的不可还原值。生物识别由系统完成，应用无法获取面容或指纹数据。

语义检索、心情建议等本机功能不会向外发送日记内容。

## 会离开设备的数据

Moodiary 可访问下列服务。请求会暴露 IP 地址等常规网络信息。除 AI 模型目录和模型下载外，各项服务都需你先配置或选用。开发者无法查看请求内容。

| 服务 | 什么时候发送 | 发送什么 |
| --- | --- | --- |
| 你配置的 AI 服务商 | 向 AI 助手发送消息时 | 消息、附件、会话上下文、助手通过工具读取的相关日记内容，以及 API Key |
| [models.dev](https://models.dev/) | 查看或选择预设 AI 服务商和模型时 | 获取模型目录和服务商图标的请求，不含日记内容 |
| 你配置的 WebDAV 或 S3 服务 | 同步或备份时 | 日记、媒体、设置和服务凭据。开启端到端加密后，服务方只能看到密文 |
| 同一局域网内的其他设备 | 发起局域网传输并输入配对码时 | 你选中的日记数据，传输过程加密 |
| [和风天气](https://www.qweather.com/)或自定义 API 地址 | 配置后，为日记获取天气或地点时 | 坐标、语言设置和 API Key |
| [OpenStreetMap](https://www.openstreetmap.org/) 或[天地图](https://www.tianditu.gov.cn/) | 选用该地图源并查看地图时 | 瓦片请求会透露查看的区域；天地图还会收到 API Key |
| [Hugging Face](https://huggingface.co/) 或自定义下载源 | 下载本机模型时 | 下载模型文件的请求，不含日记内容 |
| GitHub | 仅 Android 版，点击“检查更新”时 | 查询最新版本的请求 |

首次使用 AI 助手前，应用会说明发送哪些数据，经你同意后才能使用。使用本地部署的模型时，对话不会发送给外部服务商。

这些服务由各自的提供方或你本人运营，适用各自的隐私政策。开发者与它们没有数据共享安排。

通过系统分享面板分享的内容和外部链接，由你选择的应用或网站处理。

## 系统权限

以下权限仅在使用相应功能时请求，可在系统设置中关闭：

| 权限 | 用途 |
| --- | --- |
| 相机、麦克风 | 为日记拍照、录像、录音 |
| 照片图库 | 为日记选择照片和视频，或保存照片和视频 |
| 位置（仅使用期间） | 为日记添加地点和天气。应用不会在后台获取位置 |
| 面容 ID 或指纹 | 开启应用锁后解锁应用 |
| 本地网络 | 与同一 Wi-Fi 下自己的其他设备互传数据 |

## 数据保留与删除

数据保留在设备上，直到你删除。

- **日记：** 删除后先进入回收站，从回收站删除才会彻底清除。
- **本地数据：** 卸载应用即可删除，但 iOS 钥匙串凭据可能保留。开启系统备份后，设备备份也可能包含应用数据，需在系统设置中管理。
- **已同步数据：** 在自己的 WebDAV 或 S3 服务上删除。
- **已发送给 AI 服务商或其他第三方的数据：** 按该服务的政策处理。
- **撤回同意：** 停用相应功能，在应用内移除凭据，并在系统设置中关闭相关权限。

开发者不持有你的数据，无法替你查询、导出或删除。你可以在应用内查看、修改和导出自己的数据。

## 应用商店

App Store 等下载平台按各自的隐私政策处理下载数据，可能向开发者提供汇总的下载和使用统计，以及用户同意共享的崩溃报告，均不含日记内容。

## 未成年人

Moodiary 不面向特定年龄段，也不会有意收集任何人的个人信息。未成年人应在监护人指导下使用，尤其是配置或使用第三方服务时。

## 本站与社区

本政策只适用于 Moodiary 应用。文档站使用访问统计服务，[官方论坛](https://answer.moodiary.net)是独立系统，两者都会处理访问信息。

## 政策变更

政策变更会更新本页和生效日期，历史版本可在[文档仓库](https://github.com/ZhuJHua/moodiary-docs)查看。

## 联系方式

可通过 [GitHub Issues](https://github.com/ZhuJHua/moodiary/issues) 或[官方论坛](https://answer.moodiary.net)联系。请勿公开发布日记内容、API Key 等敏感信息。
