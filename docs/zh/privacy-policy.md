# 隐私政策

**生效日期：2026 年 11 月 2 日**

Moodiary（以下简称“本应用”）是由 ZhuJHua 与社区贡献者（以下统称“开发者”）共同开发的开源日记应用，[源代码](https://github.com/ZhuJHua/moodiary)公开，可供查阅与核验。

本政策说明本应用在运行过程中如何处理你的信息。请在使用本应用前完整阅读；你开始使用本应用，即表示已理解本政策所述的处理方式。

## 适用范围

本政策适用于本应用在各平台提供的全部客户端版本。本政策中的“你”指本应用的最终用户；“开发者”指本应用的开源作者及贡献者。

## 概览

- **开发者不收集你的数据。** 本应用没有账号系统，也没有存放日记的服务器。
- **本应用未集成广告、统计分析或崩溃上报 SDK，** 不会对你进行跨应用或跨网站的追踪。
- **数据默认保存在你的设备上。** 仅当你使用下文所列功能时，相关数据才会发送至对应服务。

## 保存在设备上的数据

本应用在其私有存储空间中保存下列数据：

- 日记内容、图片、视频、录音、心情、分类和标签；
- 日记关联的地点与天气信息；
- AI 助手的会话记录与长期记忆；
- 应用设置与错误日志（日志仅保存在本机，不会自动上传）。

API Key 与同步凭据保存在系统提供的安全存储中。应用锁仅保存由密码经 Argon2id 派生的不可还原校验值；生物识别由操作系统完成，本应用无法获取你的面容或指纹数据。

语义检索、心情建议等本机功能在设备内完成计算，不会向外发送日记内容。

## 会离开设备的数据

本应用可访问下列服务。网络请求本身会向接收方暴露 IP 地址等常规连接信息。除 AI 模型目录与模型下载外，各项服务均需你先完成配置或主动启用；开发者不参与这些传输，也无法查看其内容。

| 接收方 | 触发情形 | 传输内容 |
| --- | --- | --- |
| 你自行配置的 AI 服务商 | 向 AI 助手发送消息时 | 你发送的消息与附件、会话上下文、助手通过工具调用读取的相关日记内容，以及用于身份验证的 API Key |
| [models.dev](https://models.dev/) | 查看或选择预设的 AI 服务商与模型时 | 拉取模型目录与服务商图标的请求，不含日记内容 |
| 你自行配置的 WebDAV 或 S3 服务 | 执行同步或备份时 | 日记、分类、媒体文件与同步凭据。启用端到端加密后，服务方仅能接触密文 |
| 同一局域网内你配对的设备 | 发起局域网传输并完成配对时 | 对方设备还没有的日记、分类和媒体文件。传输内容经配对码协商的密钥加密 |
| [和风天气](https://www.qweather.com/)或你指定的 API 地址 | 完成配置后，为日记获取天气或地点信息时 | 坐标、语言设置与 API Key |
| [OpenStreetMap](https://www.openstreetmap.org/)或[天地图](https://www.tianditu.gov.cn/) | 选用该地图源并浏览地图时 | 地图瓦片请求，会反映你所查看的区域；使用天地图时还会附带你的 API Key |
| [Hugging Face](https://huggingface.co/)或你指定的下载源 | 下载本机模型时 | 下载模型文件的请求，不含日记内容 |
| GitHub | 在应用内检查更新时（仅 Android 版） | 查询最新发行版本的请求 |

首次使用 AI 助手前，本应用会以专门提示说明将向外部服务商发送哪些数据，你确认同意后方可使用该功能。若你使用本地部署的模型，对话内容不会被发送至外部服务商。

上述服务由相应提供方或你本人运营，分别适用其自身的隐私政策与数据处理规则。开发者与上述提供方之间不存在任何数据共享安排。

你通过系统分享面板分享的内容，以及你打开的外部链接，均由你选择的应用或网站处理。

## 系统权限

下列权限仅在你使用相应功能时请求，你也可随时在系统设置中关闭：

| 权限 | 用途 |
| --- | --- |
| 相机、麦克风 | 为日记拍摄照片、录制视频或录音 |
| 照片图库 | 选择照片和视频加入日记，或将日记中的照片和视频保存至图库 |
| 位置（仅使用期间） | 为日记添加地点与天气信息。本应用不会在后台获取或持续追踪你的位置 |
| 面容 ID 或指纹 | 在开启应用锁后用于解锁本应用 |
| 本地网络 | 在同一 Wi-Fi 下与其他设备互传日记数据 |

## 数据保留与删除

数据保存在你的设备上，直至你主动删除。

- **日记：** 删除后先移入回收站，自回收站彻底删除后才会被清除。
- **AI 助手记忆：** 清除后即被永久删除，不进入回收站，且无法恢复。
- **本地数据：** 卸载本应用即可删除；但 iOS 钥匙串中的凭据可能仍然保留。若你启用了系统备份，设备备份中可能包含本应用的数据，需在系统设置中管理。
- **已同步数据：** 需在你自己的 WebDAV 或 S3 服务上删除。
- **已发送至 AI 服务商或其他第三方的数据：** 依该服务提供方的政策处理，开发者无法代为删除。
- **撤回同意：** 停用相应功能、在应用内移除相关凭据，并在系统设置中关闭对应权限。

由于开发者不持有你的数据，无法代为查询、导出或删除。你可以随时在应用内查看、修改和导出自己的数据。

## 应用商店

App Store 等分发平台依其自身隐私政策处理下载与安装数据，并可能向开发者提供汇总的下载量、使用统计，以及经用户同意共享的崩溃报告。上述信息均不含日记内容。

## 未成年人

本应用不面向特定年龄段用户，开发者亦不会主动收集任何用户的个人信息。未成年人应在监护人指导下使用本应用，在配置或使用第三方服务时尤应如此。

## 政策变更

本政策发生变更时，将更新本页面内容与生效日期。历史版本可在[文档仓库](https://github.com/ZhuJHua/moodiary-docs)中查阅。

## 联系方式

如对本政策有疑问，可通过 [GitHub Issues](https://github.com/ZhuJHua/moodiary/issues) 与开发者联系。请勿在该公开渠道发布日记内容、API Key 等敏感信息。
