# Quick start

This guide gets you to your first entry in five minutes.

## 1. Create your first entry

Open the app and tap the **New** button in the bottom-right corner:

1. Type a title and body. The body supports mixed text and images, and Markdown syntax too;
2. Tap the icons in the toolbar to insert an image, audio, or video;
3. Pick a [category](./organize#categories) for the entry so you can find it later;
4. Changes are saved automatically; check the save status before leaving.

Entries are saved to your local database without a network connection.

## 2. Look back with the calendar

Open **Me → Revisit → Calendar** to browse by month or year, then tap a day to read its entries.

## 3. Find an entry again

Tap the search box at the top of the home screen and type a keyword to run a full-text search. If you've forgotten the keyword, turn on [semantic search](./organize#semantic-search) and just describe the entry in a sentence.

## 4. Pick a style you like

Open **Settings**, where you can:

- Switch between light and dark mode, and choose an accent color (the default is grayscale) under **Display**;
- Import your own fonts, including variable fonts, under **Font**.

## 5. Where to go next

- Want the same diary on several devices? Read [Backup and sync](./sync).
- Want your diary as a Word file, PDF, or long image? Read [Export, import and share](./export-import).
- Want the weather and places to show up in your entries automatically? Read [Weather, places and footprints](./weather-and-places), and configure the relevant [services](../services/).
